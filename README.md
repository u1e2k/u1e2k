## 👤 About Me

フリーランスのインフラエンジニアおよびダンスイベントのメディアオペレーターとして活動しています。  
「**世の中をもっと便利に、面白くする**」をモットーに、サーバー・ネットワークの構築運用から、日々の課題を自動化・効率化するWeb/デスクトップツールの開発、AI（LLM/RAG）の活用、Godot Engineによるゲーム制作まで幅広くチャレンジしています。

- 💻 **Infrastructure & Virtualization**: 自宅・小型サーバー（Proxmox VE / HPE ProLiant / LXC）、NixOS、Linux環境の構築・運用
- 🛠️ **App & Tool Development**: TypeScript / React / Expo / Electron を用いた実用的なツール・拡張機能開発
- 🎮 **Game Development**: Godot Engine (Godot 4 / GDScript) によるゲーム制作

- 🎵 **Media & Event Operations**: ダンスイベント等の現場における音響・映像・メディアオペレーション
